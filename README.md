# SmartSched: Intelligent Academic Timetable Manager

**SmartSched** is an automated scheduling platform designed to eliminate the headache of manual timetable creation in academic institutions. By balancing the availability of teachers, the capacity of classrooms, and the needs of students, it creates conflict-free schedules at the click of a button[cite: 1].

---

## 🌟 What it Does
Creating a school or college timetable is like solving a massive puzzle[cite: 1]. **SmartSched** takes all your raw data—your list of teachers, subjects, rooms, and sections—and uses an intelligent generator to build the perfect schedule for everyone[cite: 1].

*   **Conflict-Free Scheduling:** Ensures no teacher is scheduled for two classes at once[cite: 1].
*   **Optimal Room Usage:** Guarantees no classroom is double-booked[cite: 1].
*   **Student Logic:** Organizes a logical flow to the academic day for all sections[cite: 1].

---

## 👥 User Roles
The system provides a tailored experience for three different types of users[cite: 1]:

### 🎓 For Students
*   **Personalized View:** Access a clear, easy-to-read daily and weekly schedule[cite: 1].
*   **Real-time Updates:** Stay informed about where you need to be and which subject is being taught[cite: 1].

### 👩‍🏫 For Faculty
*   **Teaching Schedule:** View a dedicated dashboard showing your specific teaching hours[cite: 1].
*   **Subject Management:** Track the subjects assigned to you across different departments[cite: 1].

### 🏛️ For HODs & Administrators
*   **The "Brain" Center:** Manage the master list of departments, classrooms, and academic sessions[cite: 1].
*   **Automated Generation:** Use the built-in generator to create entire timetables instantly[cite: 1].
*   **Resource Management:** Easily add or edit faculty members, students, and classroom details[cite: 1].

---

## 🚀 Key Features
*   **Smart Timetable Generator:** An advanced algorithm that handles complex constraints to prevent scheduling conflicts[cite: 1].
*   **Role-Based Dashboards:** Unique interfaces for Students, Faculty, and Heads of Departments (HOD)[cite: 1].
*   **Centralized Database:** One place for all academic data—no more messy spreadsheets[cite: 1].
*   **Academic Session Tracking:** Organize schedules by semester or yearly terms[cite: 1].

## 🛠️ Tech Stack
Built on a modern and robust engine[cite: 1]:

*   **Frontend:** Next.js and Tailwind CSS for a fast, responsive interface[cite: 1].
*   **Backend:** A powerful API built with NestJS[cite: 1].
*   **Database:** Secure data management using Prisma and a relational database[cite: 1].
*   **Deployment:** Configured for easy hosting via Render[cite: 1].
